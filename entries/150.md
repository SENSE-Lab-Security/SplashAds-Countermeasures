### What it does

Disable splash ads by shaking with shakable=``0''

### Limits and notes

Omitting this parameter or setting it to 1 will not prevent shaking; the documentation is not clear about the version in which this parameter first appeared.

### Before use

This is an application or ad platform setting, not a standalone installable package
