### What it does

Uses a local VPN to observe the network endpoints connected by the app, and use the advertising/tracking database to classify and block the corresponding connections.

### Limits and notes

The focus is on tracker/third-party endpoint control; ads that are first-party or share infrastructure with normal content are harder to distinguish.

### Before use

Will take over part of the network connection or DNS resolution

## Technical notes

### Working method

**Where it starts:** TrackerControl observes which network endpoints the app is accessing via a local VPN.<br>
**How it decides:** Matches and classifies domains/endpoints against the tracker/ad database; it identifies web targets, not on-screen ads.<br>
**What it does:** Deny connections by category, domain, or user rule during the network connection phase.<br>
**Possible result:** The hit ad/tracking server cannot continue communication.

### Coverage

Both (source network blocking, conditional) | The third-party network endpoint and tracking connection hit by the tracker/ad database

### Intervention point

Local VPN (VpnService) + tracker/ad domain database
