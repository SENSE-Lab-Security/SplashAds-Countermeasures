### What it does

Uses the accessibility service to read the UI tree and look for qualified skip/close controls. Once found, directly call the accessibility click.

### Limits and notes

It is only effective for controls that can be recognized by accessibility; it does not prevent ads from loading, and does not handle triggering logic such as shaking.

### Before use

Only grant accessibility permissions to trusted sources

## Technical notes

### Working method

**Where it starts:** mirad-tech/Skip Reads the accessibility UI tree of the current page via Accessibility Services.<br>
**How it decides:** Look for explicit skip/close controls based on preset conditions.<br>
**What it does:** Calls accessibility node taps during the UI presentation phase.<br>
**Possible result:** Accessible skip/close buttons will be automatically clicked; earlier stages such as ad loading, sensor triggering, etc. will not be affected.

### Coverage

Display-only｜Normal splash ads, identifiable close/skip controls

### Intervention point

Accessibility Services + UI Tree Matching
