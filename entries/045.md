### What it does

System and application interface customization modules, including some system recommendation/advertising purification capabilities.

### Limits and notes

There are many functions and are highly dependent on ROM/version; advertising-related capabilities need to be verified item by item and cannot be summarized by a general workflow.

### Before use

May affect system security or application stability

## Technical notes

### Working method

**Where it starts:** HyperCeiler is a system/application customization module,<br>
**How it decides:** Uses LSPosed to hook MIUI/HyperOS systems and application methods by function.<br>
**What it does:** If a certain recommendation/advertising purification item is enabled, the real determination and interception will occur at the internal call point corresponding to the function;<br>
**Possible result:** The current master profile does not give a unified advertising workflow, so the entire project is not equated to a dedicated ad blocker.

### Coverage

Display-only (confirmable range of current public information)｜Recommended/advertising purification items in HyperOS/MIUI systems or applications; the specific range is affected by ROM and version

### Intervention point

Root; LSPosed + app/SDK/UI runtime hook
