### What it does

The old version of the MIUI system enhancement module includes some system application interface purification capabilities.

### Limits and notes

It is not a dedicated advertising tool, and the ROM/Android version has obvious restrictions; advertising-related capabilities need to be verified based on specific functional items.

### Before use

May affect system security or application stability

## Technical notes

### Working method

**Where it starts:** Cemiuiler is similar to HyperCeiler,<br>
**How it decides:** The core is to modify the Xposed function of the old MIUI system/application.<br>
**What it does:** Ads will only be affected if the specific purification/recommendation switch hits the corresponding internal method;<br>
**Possible result:** The project itself does not have a unified "detect ads → block ads" process. The specific mechanism needs to be verified separately by function item and ROM version.

### Coverage

Display-only (the scope of current public information that can be confirmed)｜Recommendation/interface purification items in old versions of MIUI system applications; specific advertising items need to be verified according to the version

### Intervention point

Root; LSPosed + app/SDK/UI runtime hook
