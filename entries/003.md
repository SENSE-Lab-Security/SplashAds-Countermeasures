### What it does

Leverage accessibility services to identify targets by keyword, UI control, or coordinates and automatically handle splash ads with accessible taps.

### Limits and notes

Rely on page recognition and rule maintenance; fixed coordinates are sensitive to layout changes, and custom-rendered UI may not be able to match stably.

### Before use

Only grant accessibility permissions to trusted sources

## Technical notes

### Working method

**Where it starts:** Android-Touch-Helper uses accessibility services to read the current page,<br>
**How it decides:** You can find targets by text keywords, specific UI controls or preset coordinates.<br>
**What it does:** After the rule is hit, it still operates the corresponding position through barrier-free taps/gestures,<br>
**Possible result:** So it is suitable for automatically clicking "Skip/Close", but it does not prevent the ad resource itself from loading.

### Coverage

Display-only | Screen-opening "skip/close" targets that can be positioned via text, UI controls, or fixed coordinates

### Intervention point

Accessibility services + keywords/UI controls/coordinate matching
