### What it does

Automatically skips adapted launch ads using offline deterministic rules and per-app policies.

### Limits and notes

The adaptation scope is determined by existing rules, and the rules need to be updated after the app page structure changes.

### Before use

Please only grant accessibility permissions to trusted sources; more suitable for developers or researchers, and cannot be installed directly as a normal app

## Technical notes

### Working method

**Where it starts:** PureSkip uses Accessibility Services to observe the startup page,<br>
**How it decides:** and match text, resource ID, node relationship or coordinates according to each app's offline rules.<br>
**What it does:** After the rule is hit, directly use the barrier-free click to complete the skip;<br>
**Possible result:** It does not require an Internet connection to determine advertising, but the adaptation effect depends on whether the existing rules cover the current version.

### Coverage

Display-only｜There are already startup ads and skip controls covered by offline application rules

### Intervention point

Accessibility Services + Offline Rules + Per-app Policies
