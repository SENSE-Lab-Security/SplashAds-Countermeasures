### What it does

Used to handle ad requests, ad interfaces, or ad redirects, depending on the apps and versions supported by the project.

### Limits and notes

Only for Coolan and known SplashAdActivity startup paths; if the splash ad uses other components or implementations, the original hook may be invalid.

### Before use

May affect system security or application stability

## Technical notes

### Working method

**Where it starts:** The corresponding platform, permissions or runtime environment need to be configured according to the original project instructions.<br>
**How it decides:** When the target is `SplashAdActivity` known to the project, this Activity startup is judged as an splash advertising process.<br>
**What it does:** Directly block this `execStartActivity` call before the Activity is actually started.<br>
**Possible result:** The page corresponding to the splash ad has no chance to enter the foreground; if Coolan uses other components to implement the splash ad, the original rules will no longer be covered.

### Coverage
