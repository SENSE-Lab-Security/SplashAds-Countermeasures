### What it does

Accessibility services, whitelists, and rule interfaces are declared in the source code to identify and close or skip splash ads.

### Limits and notes

Currently, its accessibility/rule capabilities are mainly confirmed from the Manifest and source code structure. There is a lack of mature product documentation and independent evaluation, and the actual coverage is still unclear.

### Before use

Please only grant accessibility permissions to trusted sources; more suitable for developers or researchers, and cannot be installed directly as a normal app

## Technical notes

### Working method

**Where it starts:** SplashGuard's source code declares accessibility services, whitelists, and rule configurations.<br>
**How it decides:** At runtime it uses Accessibility Services to watch the startup page and read accessible nodes,<br>
**What it does:** Then locate the skip target according to the package name/control text, resource ID or coordinates and other rules, and call the barrier-free click/gesture to complete the closure after hitting it;<br>
**Possible result:** There is currently a lack of mature product documentation, and specific rule coverage still requires actual testing.

### Coverage

Display-only | Open-screen ad skip control that can be described by whitelist/rules and accessible nodes can locate

### Intervention point

Accessibility services + UI nodes/keywords/coordinate rules + click gestures
