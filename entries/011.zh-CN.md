## 技术说明

### 工作方式

**从哪里开始：**SkipAds 加载 JSON 规则后，用 无障碍服务 监听当前页面并读取可访问控件。<br>
**如何判断：**将 App、页面、元素属性/状态与 JSON 中定义的条件匹配。<br>
**怎么处理：**规则命中后在 UI 层调用无障碍点击或相应自动化动作。<br>
**可能结果：**规则可描述的广告 UI 被自动跳过/关闭；页面结构变化后需更新配置。

### 可覆盖场景

纯展示型｜白名单/配置规则能够描述的开屏广告按钮和页面状态

### 干预位置

无障碍服务 + UI 节点/关键词/坐标规则 + 点击手势
