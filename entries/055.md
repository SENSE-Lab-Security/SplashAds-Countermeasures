### What it does

Cloud-encrypted DNS firewall with support for ad/tracking lists, logging and per-configuration controls.

### Limits and notes

Page/request content semantics are not visible to the DNS layer, and first-party shared domains, caches, and built-in ads are still bypassed.

### Before use

Will take over part of the network connection or DNS resolution

## Technical notes

### Working method

**Where it starts:** After a device or router sends a DNS query to NextDNS's managed resolver, the query first enters its server-side filtering process.<br>
**How it decides:** NextDNS determines whether a domain should be released based on advertising, tracking, malicious domain classification, and user-defined rules.<br>
**What it does:** When a rule is hit, the result is rejected or rewritten during the DNS resolution phase, so that the client cannot obtain the corresponding server address.<br>
**Possible result:** Advertising/tracking resources that rely on these domains cannot be loaded online; shared domains, caches, and in-app content can still be bypassed.

### Coverage

Both (source network blocking, conditional)｜Advertising, tracking and malicious domains hit by NextDNS classification or custom rules

### Intervention point

Hosted Encrypted DNS + Domain Classification/Custom Rules
