### What it does

The LSPosed module does not remove the ad itself, but instead parses the hook URI and invalidates the Taobao/JD specific Deep Link, thereby preventing the ad from pulling users to Taobao or JD app.

### Limits and notes

Only covers the Taobao/JD URI scheme explicitly handled by the project; requires LSPosed/Xposed. If the target app uses another scheme, normal HTTP/app Link, explicit Intent, or other jump paths, it may not be affected by this hook; the ad itself will not be removed.

### Before use

May affect system security or application stability

## Technical notes

### Working method

**Where it starts:** The corresponding platform, permissions or runtime environment need to be configured according to the original project instructions.<br>
**How it decides:** When the URI to be parsed is not an ordinary http link and starts with `openapp.jdmobile` or `tbopen`, it is determined to be a JD/Taobao app Deep Link.<br>
**What it does:** Before Deep Link is subsequently used for external navigation, change the hit URI string to empty and cut off the original jump path from the URL/Deep Link layer.<br>
**Possible result:** The ad itself may still be displayed, and the source app may also enter the ad content page after clicking, but the corresponding Taobao/JD app will not be pulled up according to the original Deep Link.

### Coverage

Navigation-triggering｜External app jump triggered by Taobao/JD Deep Link (tbopen, openapp.jdmobile)
