### What it does

LSPosed hook uses the known advertising entrance and runtime functions of a specific app to return or modify the results in advance when the advertising code is executed.

### Limits and notes

Requires Root/LSPosed and is only valid for adapted apps/versions; it may become invalid after the app is updated.

### Before use

May affect system security or application stability

## Technical notes

### Working method

**Where it starts:** BetterHeybox injects supported target apps via LSPosed to monitor pre-targeted ad-related functions.<br>
**How it decides:** Based on known advertising entrances/methods in a specific app.<br>
**What it does:** In the internal advertising logic stage of the app, execution is cut off by hook means such as early return and modified return value.<br>
**Possible result:** The corresponding splash screen or in-app ad cannot be displayed normally according to the original process.

### Coverage

Both (advertising logic layer)｜Open screen ads and in-app ads for specific apps

### Intervention point

LSPosed + app-specific runtime hook
