### What it does

Safari content blocker blocks web ads, trackers, and distracting elements.

### Limits and notes

Browser content only, does not handle native app ads and sensor redirects.

### Before use

Check the source, version, and permissions before use.

## Technical notes

### Working method

**Where it starts:** Wipr 2 submits network requests and page elements to content blocking rules for matching when the browser loads the page.<br>
**How it decides:** The hit URL/script will be blocked before downloading, and the hit DOM/page element will be hidden during the rendering phase,<br>
**What it does:** So it can handle web ads,<br>
**Possible result:** But it will not interfere with the opening UI, sensors or cross-app jumps of other native apps.

### Coverage

Display-only (web content layer) | Ads, trackers, and common distracting elements in Safari web pages

### Intervention point

Browser content blocking API/extension + filtering rules
