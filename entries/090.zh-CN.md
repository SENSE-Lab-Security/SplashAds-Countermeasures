### 能做什么

针对 YouTube 资源 ID 检测广告、自动静音，并在跳过按钮可点击时执行无障碍点击。

### 限制和注意事项

只针对 YouTube 的特定 resource ID；界面更新后容易失效，而且广告仍会先播放到出现可跳过控件的阶段。

### 使用前提示

请只对可信来源授予无障碍权限；更适合开发者或研究者，不能按普通 App 直接安装

## 技术说明

### 工作方式

**从哪里开始：**这个 AdSkipper 专门面向 YouTube：无障碍服务 读取 YouTube 的可访问节点和特定 resource ID，<br>
**如何判断：**用这些标识判断当前是否进入广告/是否出现可点击的跳过按钮。<br>
**怎么处理：**检测到广告时可先自动静音，等 Skip 按钮可用后再调用无障碍点击；<br>
**可能结果：**YouTube 一旦改 UI 或 resource ID，规则就可能失效。

### 可覆盖场景

纯展示型｜YouTube 中由特定 resource ID 标识的广告状态与 Skip 按钮

### 干预位置

无障碍服务 + UI 节点/关键词/坐标规则 + 点击手势
