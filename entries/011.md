### What it does

Automatically skips ads based on accessibility services, configurable app whitelist.

### Limits and notes

There are few public documents and adaptation scope, and the current coverage and long-term stability still need to be further verified.

### Before use

Please only grant accessibility permissions to trusted sources; more suitable for developers or researchers, and cannot be installed directly as a normal app

## Technical notes

### Working method

**Where it starts:** After SkipAds loads the JSON rules, it uses Accessibility Services to listen to the current page and read accessibility controls.<br>
**How it decides:** Matches apps, pages, element properties/states to criteria defined in JSON.<br>
**What it does:** Calls accessibility taps or corresponding automation actions at the UI layer after the rule is hit.<br>
**Possible result:** The advertising UI that can be described by the rules is automatically skipped/closed; the configuration needs to be updated after the page structure changes.

### Coverage

Display-only｜Open screen advertising buttons and page states that can be described by whitelist/configuration rules

### Intervention point

Accessibility services + UI nodes/keywords/coordinate rules + click gestures
