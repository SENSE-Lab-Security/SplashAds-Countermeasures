### What it does

Disable motion interaction components via isCanUseMotionManager

### Limits and notes

This interface only covers interactive components, other advertising interactions may still exist.

### Before use

This is an application or ad platform setting, not a standalone installable package

## Technical notes

### Working method

**Where it starts:** The developer sets the corresponding interface to NO<br>
**How it decides:** Disable motion interaction components through isCanUseMotionManager<br>
**What it does:** Input or trigger restrictions<br>
**Possible result:** This interface only covers interactive components, other advertising interactions may still exist.

### Coverage

Ad triggering, display and redirection controlled by specific applications or ad platforms.

### Intervention point

Enter or trigger limits
