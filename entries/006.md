### What it does

Combining UI tree, offline OCR and position heuristics to identify splash ads, emphasizing accidental activation prevention and elderly user scenarios.

### Limits and notes

Screenshots/OCR will increase recognition latency; real advertising coverage and the effect on accidental activation/shake scenes still need to be measured.

### Before use

Only grant accessibility permissions to trusted sources

## Technical notes

### Working method

**Where it starts:** ZeroStart first uses the accessibility service to read the current UI;<br>
**How it decides:** If the node information is not enough, combine screenshots, offline OCR and position heuristics to find skip controls.<br>
**What it does:** After determining the target position, operate through barrier-free taps/gestures,<br>
**Possible result:** The focus is to improve the recognition ability of the screen opening button that is "difficult to find in the UI tree".

### Coverage

Both (UI skip, indirect anti-jump)｜Open screen skip button that is difficult to locate directly in the UI tree but can be discovered by OCR/position heuristics

### Intervention point

Accessibility Services + UI Tree Matching + Offline OCR + Location Heuristics
