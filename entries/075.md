### What it does

Hosted encrypted DNS service that blocks ads, trackers, and malicious domains by rules.

### Limits and notes

Requires trust in third-party DNS services and does not recognize content layer and shared domain ads.

### Before use

Will take over part of the network connection or DNS resolution

## Technical notes

### Working method

**Where it starts:** AdGuard DNS works at the managed DNS level:<br>
**How it decides:** After the device or router sends the DNS query to it, the server uses the advertising/tracking domain classification and user rules to determine whether to allow it.<br>
**What it does:** Hit domains are rejected or rewritten during the resolution phase, so creatives that rely on these domains cannot get the server address;<br>
**Possible result:** It does not see the app interface, nor can it understand a shake or click.

### Coverage

Both (source network blocking, conditional)｜Advertising, tracking and malicious domains hit by AdGuard DNS classification/custom rules

### Intervention point

Hosted Encrypted DNS + Domain Classification/Custom Rules
