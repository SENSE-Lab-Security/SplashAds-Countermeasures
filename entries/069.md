### What it does

Offers Safari content blocking, anti-tracking, and configurable encrypted DNS and custom filtering subscriptions.

### Limits and notes

Safari content blocking only works in the browser; cross-app filtering relies heavily on DNS and is therefore still subject to domain granularity.

### Before use

Will take over part of the network connection or DNS resolution

## Technical notes

### Working method

**Where it starts:** When the browser loads the web page or WebView content, it hands the resource request and page elements to the content interception extension/engine.<br>
**How it decides:** Matches URLs, scripts, or DOM elements based on advertising, privacy, and custom filtering rules.<br>
**What it does:** Reject the request before the resource is loaded, or hide matching elements during the page rendering phase.<br>
**Possible result:** Web page ads and related tracking requests are reduced, but splash ads of other native apps are not protected.

### Coverage

Both (web content + DNS network layer, conditional)｜Safari web page advertising/tracking elements, and some cross-app domain requests recognized by the DNS layer

### Intervention point

Browser content blocking API/extension + filtering rules
