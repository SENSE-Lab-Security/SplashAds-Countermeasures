### What it does

Uses accessibility services to automatically click on skippable ad buttons when they appear in the official YouTube app.

### Limits and notes

Only for YouTube skippable ads, does not handle splash ads or non-skippable ads.

### Before use

Only grant accessibility permissions to trusted sources

## Technical notes

### Working method

**Where it starts:** Accessibility service listens for application startup or window changes and reads accessible UI nodes.<br>
**How it decides:** Skip/close targets based on package name, page, text, resource ID, node relationship or coordinate rule matching.<br>
**What it does:** Calls the accessibility node click or gesture gesture action target after the ad UI has appeared.<br>
**Possible result:** The ad will usually still load first or show briefly, but the skip/close action will be automatically performed if a match is successful.

### Coverage

Display-only｜The Skip Ad control in the YouTube official app enters a clickable state

### Intervention point

Accessibility services + UI nodes/keywords/coordinate rules + click gestures
