### What it does

Uses Xposed to add Hooks/filtering in Activity, View, WebView, Receiver, hosts and other locations to block advertising components, requests or displays from different entrances.

### Limits and notes

It is an older multi-point hook solution with limited compatibility with modern Android/Apps; multiple hook points are also more likely to become invalid with system or app updates.

### Before use

May affect system security or application stability

## Technical notes

### Working method

**Where it starts:** The corresponding platform, permissions or runtime environment need to be configured according to the original project instructions.<br>
**How it decides:** Rely on the corresponding hook points and filtering rules to determine which components, requests or content belong to the advertising-related process.<br>
**What it does:** Block/modify calls during component creation, page display, or network access stages according to the scenario.<br>
**Possible result:** Some ads can be blocked at various stages, but the solution is older and has limited compatibility with modern apps/Android.
