### What it does

The Magisk module for the Qiudi application combines file permissions, network and DNS rules to handle screen opening and information flow ads.

### Limits and notes

Only for players who understand football; there are compatibility risks with daemon processes, cache directory permissions and iptables rules.

### Before use

May affect system security or application stability

## Technical notes

### Working method

**Where it starts:** Dongqiudi AdBlock is a combined Magisk module for football players.<br>
**How it decides:** It limits writes to known ad cache directories,<br>
**What it does:** Uses hosts and iptables/ipset to match the advertising endpoints maintained by the project and block communication, thus reducing advertising caching and network loading at the same time;<br>
**Possible result:** The rules are bound to the specific implementation of the QQD/Advertising SDK and may need to be re-adapted after updates.

### Coverage

Both (multi-layer source blocking, conditional) | Understand the Qiudi screen opening/information flow advertising cache, and known advertising endpoints such as Pangolin, Guangdiantong, Kuaishou, Baidu, and Google Ads
