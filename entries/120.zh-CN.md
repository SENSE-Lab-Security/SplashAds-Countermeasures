### 能做什么

基于 apktool + smali 的 Python APK reverse/patch 工具，README 明确提供多种 rmads 去广告方法，可修改 Manifest、权限、广告 ID 与广告 loader 后重新打包。

### 限制和注意事项

通用逆向/补丁工具而非广告专用 App，但 README 明确提供 rmads 功能。某些方法（如移除 INTERNET 权限）粒度很粗，会同时影响正常联网；重打包也可能触发签名/完整性校验。

### 使用前提示

修改版应用可能带来签名、更新、账号和供应链风险

## 技术说明

### 工作方式

**从哪里开始：**用户把目标 APK 交给 DTL-X，由工具通过 apktool/smali 反编译后执行选定的 rmads 规则。<br>
**如何判断：**依据预置字符串、Manifest 项、广告 ID 和 loader 字典等特征匹配广告相关内容，例如 com.google.android.gms.ad、ca-app-pub。<br>
**怎么处理：**静态修改 AndroidManifest.xml、权限、字符串和 smali/广告 loader，然后重新编译并签名 APK。<br>
**可能结果：**命中的广告组件、广告 ID、loader 或联网路径被修改/禁用，使修改版 App 的相关广告无法按原流程加载或展示。

### 可覆盖场景

两者（静态修改层）｜DTL-X rmads 规则可匹配的 Android APK 广告组件、广告 ID、广告 loader 与联网权限
