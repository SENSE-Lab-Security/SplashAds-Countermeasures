### 能做什么

LSPosed 模块，不移除广告本身，而是 Hook URI 解析并使淘宝/京东特定 Deep Link 失效，从而阻止广告把用户拉起到淘宝或京东 App。

### 限制和注意事项

只覆盖项目明确处理的淘宝/京东 URI scheme；需要 LSPosed/Xposed。若目标应用改用其他 scheme、普通 HTTP/App Link、显式 Intent 或其他跳转路径，可能不受该 Hook 影响；广告本身不会被移除。

### 使用前提示

可能影响系统安全或应用稳定性

## 技术说明

### 工作方式

**从哪里开始：**需要按原始项目说明配置相应的平台、权限或运行环境。<br>
**如何判断：**当待解析 URI 不是普通 http 链接，且以 `openapp.jdmobile` 或 `tbopen` 开头时，判定为京东/淘宝 App Deep Link。<br>
**怎么处理：**在 Deep Link 被后续用于外部导航之前，把命中的 URI 字符串改为空，从 URL/Deep Link 层切断原跳转路径。<br>
**可能结果：**广告本身仍可能显示，点击后源 App 也可能进入广告内容页，但对应淘宝/京东 App 不会按原 Deep Link 被拉起。

### 可覆盖场景

触发跳转型｜淘宝/京东 Deep Link（tbopen、openapp.jdmobile）触发的外部 App 跳转
