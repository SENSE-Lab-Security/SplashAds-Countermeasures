### What it does

Provides an iOS graphical interface for dnscrypt-proxy 2, with the option of a DNS resolver with ad filtering.

### Limits and notes

It does not define advertising rules, and the filtering effect depends on the parser; the project technology stack is older.

### Before use

More suitable for developers or researchers, it cannot be installed directly as a normal app.

## Technical notes

### Working method

**Where it starts:** DNSCloak catches DNS queries on your phone,<br>
**How it decides:** Then hand it over to the upstream parser through DoH/DoT/DNSCrypt etc.;<br>
**What it does:** If hosts/blocklist is enabled, the domain is determined locally and hits are rejected.<br>
**Possible result:** It causes web ads that rely on these domains to fail to load, but does not handle already displayed UI, sensor triggers, or subsequent navigation.

### Coverage

Both (source network blocking, conditional)｜The selected dnscrypt-proxy/filter DNS upstream can intercept domain-level advertising requests

### Intervention point

Local DNS/VPN + DoH/DoT/DNSCrypt upstream configuration
