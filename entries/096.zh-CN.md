### 能做什么

利用 LSPosed/Xposed Hook 广告 SDK、网络和 SensorManager 等调用，在广告初始化/加载或 shake 监听阶段直接截断逻辑。

### 限制和注意事项

通常需要 Root + LSPosed/Xposed；App/SDK 更新、代码混淆、动态加载或 native 实现都可能让 Hook 失效，需要持续适配。

### 使用前提示

可能影响系统安全或应用稳定性

## 技术说明

### 工作方式

**从哪里开始：**AdClose 通过 LSPosed/Xposed 注入目标 App，并监控预先适配的广告 SDK 方法、网络调用或 SensorManager 监听注册。<br>
**如何判断：**当已知广告 SDK/传感器相关类和方法被调用时，认为相应广告或 shake 逻辑正在执行；不是通过 UI 识别广告。<br>
**怎么处理：**在广告 SDK/App logic 或传感器 listener 注册阶段直接短路方法、修改返回值或阻止/移除监听。<br>
**可能结果：**广告 SDK 可能无法初始化/加载，或 shake 监听无法建立，从而更早切断广告/触发链。

### 可覆盖场景

两者（多层防护）｜开屏/应用内广告、摇一摇触发广告

### 干预位置

LSPosed/Xposed + 广告 SDK/API Hook + 传感器监听控制
