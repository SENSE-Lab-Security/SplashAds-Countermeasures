### What it does

First use the Accessibility node to find the skip button. If it fails, use screenshot + OCR/YOLO/VLM to locate it and click it through accessibility gestures.

### Limits and notes

Visual recognition is slower than pure UI node matching, and may also be produce false positives or missed detections; for ads that trigger redirects as soon as they appear, it may be too late by the time the recognition is completed.

### Before use

Only grant accessibility permissions to trusted sources

## Technical notes

### Working method

**Where it starts:** This Ad Skipper matches the Accessibility node with the lowest cost first;<br>
**How it decides:** Take a screenshot when you can't find the skip button, use OCR, YOLO, and VLM grounding to locate the target if necessary.<br>
**What it does:** Regardless of whether the target comes from a node or a visual coordinate, it is finally executed through Accessibility's click/gesture,<br>
**Possible result:** Therefore, it extends "how to find the button", not the interception during the ad loading stage.

### Coverage

Display-only｜When the accessibility tree is missing or self-drawn, the screen-opening skip button can still be positioned by OCR/YOLO/VLM

### Intervention point

Accessibility + Screenshot + OCR/YOLO/VLM + Accessibility Gestures
