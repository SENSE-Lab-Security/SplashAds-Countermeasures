## Technical notes

### Working method

**Where it starts:** TapClick/ADGO reads UI nodes with Accessibility Services,<br>
**How it decides:** You can also fall back to keyword or coordinate rules.<br>
**What it does:** After matching the "skip/close" position that requires operation,<br>
**Possible result:** Executed through barrier-free taps/gestures, so it is sensitive to page structure and coordinate stability.

### Coverage

Display-only | Open-screen ads and pop-up window controls that can be positioned by accessible nodes, keywords or coordinate rules

### Intervention point

Accessibility services + UI nodes/keywords/coordinate rules + click gestures
