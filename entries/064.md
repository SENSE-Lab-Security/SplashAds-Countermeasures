## Technical notes

### Working method

**Where it starts:** Daedalus catches DNS query on mobile phone,<br>
**How it decides:** Then hand it over to the upstream parser through DoH/DoT/DNSCrypt etc.;<br>
**What it does:** If hosts/blocklist is enabled, the domain is determined locally and hits are rejected.<br>
**Possible result:** It causes web ads that rely on these domains to fail to load, but does not handle already displayed UI, sensor triggers, or subsequent navigation.

### Coverage

Both (source network blocking, conditional)｜Domain name requests filtered by local rules or selected DoH/DoT/DNSCrypt upstream

### Intervention point

Local DNS/VPN + DoH/DoT/DNSCrypt upstream configuration
