### What it does

Detect ads against YouTube property IDs, automatically mute them, and perform accessibility taps when the skip button is clickable.

### Limits and notes

Only for YouTube-specific resource IDs; prone to breaking after interface updates, and ads will still play to a stage where skippable controls appear.

### Before use

Please only grant accessibility permissions to trusted sources; more suitable for developers or researchers, and cannot be installed directly as a normal app

## Technical notes

### Working method

**Where it starts:** This AdSkipper targets YouTube specifically: Accessibility Services reads YouTube's accessible nodes and specific resource IDs,<br>
**How it decides:** Uses these identifiers to determine whether you are currently entering an ad/whether a clickable skip button appears.<br>
**What it does:** When an ad is detected, it can be automatically muted first, and then call accessibility taps after the Skip button is available;<br>
**Possible result:** Once YouTube changes the UI or resource ID, the rules may become invalid.

### Coverage

Display-only | Ad status and Skip button identified by specific resource ID in YouTube

### Intervention point

Accessibility services + UI nodes/keywords/coordinate rules + click gestures
