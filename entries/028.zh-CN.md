### 能做什么

利用 Xposed/LSPosed Hook 开屏 Activity、Splash 容器和第三方广告 SDK 初始化，在广告组件创建/SDK 启动前阻断。

### 限制和注意事项

依赖逐 App/SDK 的内部类和方法；代码混淆、版本更新、动态加载或 native 实现都会降低 Hook 稳定性。

### 使用前提示

可能影响系统安全或应用稳定性

## 技术说明

### 工作方式

**从哪里开始：**LiTianSuo 注入目标 App，监控开屏 Activity、Splash 容器创建和第三方广告 SDK 初始化等已适配调用。<br>
**如何判断：**根据特定 App/SDK 的已知类、组件和方法判断广告流程正在启动。<br>
**怎么处理：**在 Activity/容器创建或广告 SDK 初始化阶段直接 Hook、提前返回或跳过组件启动。<br>
**可能结果：**广告组件或 SDK 无法完整启动，开屏/全屏广告可能在进入 UI 前就被阻断。

### 可覆盖场景

纯展示型｜由开屏 Activity、Splash 容器或第三方广告 SDK 初始化驱动的全屏/开屏广告
