### What it does

Configurable managed DNS filtering service with support for ads, trackers and category rules.

### Limits and notes

Not specific to mobile ads, performance is affected by domain classification and encrypted DNS bypass.

### Before use

Will take over part of the network connection or DNS resolution

## Technical notes

### Working method

**Where it starts:** Control D works at the managed DNS level: after a device or router sends a DNS query to it,<br>
**How it decides:** The server uses advertising/tracking domain classification and user rules to determine whether to release it.<br>
**What it does:** Hit domains are rejected or rewritten during the resolution phase, so creatives that rely on these domains cannot get the server address;<br>
**Possible result:** It does not see the app interface, nor can it understand a shake or click.

### Coverage

Both (source network blocking, conditional)｜Control D classification strategy or advertising/tracking domains hit by custom rules

### Intervention point

Hosted Encrypted DNS + Domain Classification/Custom Rules
