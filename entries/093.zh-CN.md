### 能做什么

利用 无障碍服务 读取 UI 树并寻找符合条件的 skip/close 控件，找到后直接调用无障碍点击。

### 限制和注意事项

只对可被无障碍识别的控件有效；不阻止广告加载，也不处理摇一摇等触发逻辑。

### 使用前提示

请只对可信来源授予无障碍权限

## 技术说明

### 工作方式

**从哪里开始：**mirad-tech/Skip 通过 无障碍服务 读取当前页面的可访问 UI 树。<br>
**如何判断：**根据预设条件寻找明确的 skip/close 控件。<br>
**怎么处理：**在 UI 展示阶段调用无障碍节点点击。<br>
**可能结果：**可访问的跳过/关闭按钮会被自动点击；广告加载、传感器触发等更早阶段不受影响。

### 可覆盖场景

纯展示型｜普通开屏广告、可识别关闭/跳过控件

### 干预位置

无障碍服务 + UI 树匹配
