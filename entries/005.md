### What it does

Uses the accessibility service to read the accessible UI of the splash screen, locate the "skip/close" control according to the rules and automatically click it.

### Limits and notes

Ads will still be displayed first; it depends on page nodes and rule adaptation. The project announced in 2023 that it would stop updating indefinitely.

### Before use

Only grant accessibility permissions to trusted sources

## Technical notes

### Working method

**Where it starts:** Li Tiaotiao turns on the accessibility service and then monitors window/page changes and reads the Accessibility Node.<br>
**How it decides:** Determines whether the "skip/close" control appears based on the rules of the target app, control text/properties, etc., rather than understanding the ad from the visual semantics.<br>
**What it does:** Calls the accessibility click capability to operate the target control during the displayed phase of the screen-opening UI.<br>
**Possible result:** The ad will usually still show first, but the tool will skip/close it for the user.

### Coverage

Display-only｜"Skip/Close" button to enter the accessibility tree on the splash screen and the adapted page

### Intervention point

Accessibility Services + UI Node Identification
