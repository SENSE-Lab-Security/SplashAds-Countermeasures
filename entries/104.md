### What it does

Uses DexKit to locate advertising methods in the current Koan version, and then use LSPosed runtime to hook these methods to suppress open screen/information flow ads.

### Limits and notes

Root/LSPosed is required; although DexKit helps adapt to version changes, the target app may still become invalid after major changes.

### Before use

May affect system security or application stability

## Technical notes

### Working method

**Where it starts:** Coolapk Purifier first uses DexKit to search for target methods that match the characteristics in the current app version, and then LSPosed intercepts these methods at runtime.<br>
**How it decides:** Uses the method/call characteristics found by DexKit that match the advertising logic as the decision point.<br>
**What it does:** hook the target method in the app advertising logic layer and modify the execution result.<br>
**Possible result:** Coolan's screen opening/information flow ads are suppressed; DexKit can improve version adaptation capabilities, but it may still fail after major revisions.

### Coverage

Both (advertising logic layer) | Coolan splash advertising, information flow advertising

### Intervention point

LSPosed + DexKit method positioning + runtime hook
