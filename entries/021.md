### What it does

Blocks confirmed open-screen or interstitial ad call chains through LSPosed rules.

### Limits and notes

Relying on the rules obtained through reverse engineering of each app, the coverage is determined by the existing rules; the call point may change after the application or SDK is revised.

### Before use

May affect system security or application stability

## Technical notes

### Working method

**Where it starts:** AdPopupBlocker injects the adapted app through LSPosed and monitors the open/interstitial ad call points determined after reverse analysis.<br>
**How it decides:** When these specific methods or call chains are hit, the current process is regarded as an ad pop-up that needs to be blocked, rather than identifying ads from UI images.<br>
**What it does:** Returns early, modify the return value, or skip subsequent calls before the ad object is created or displayed.<br>
**Possible result:** Adapted open-screen/interstitial ads cannot pop up according to the original process, but the call point may change after the application or SDK is revised.

### Coverage

Display-only｜Open screen or interstitial advertising pop-up window that has reversely located the call point

### Intervention point

Root; LSPosed + app/SDK/UI runtime hook
