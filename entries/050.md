### What it does

Uses Android VpnService to only take over DNS queries, and use hosts/blocklist to prevent resolution of ad domains.

### Limits and notes

Project is old and archived; can only handle DNS-layer distinguishable ads, not first-party, cached, or built-in ads.

### Before use

Will take over part of the network connection or DNS resolution

## Technical notes

### Working method

**Where it starts:** DNS66 Establishes a local VPN so that the device's DNS requests go through it first.<br>
**How it decides:** Compares the query domain to the advertising/tracking entries in hosts/blocklist, without analyzing the advertising page itself.<br>
**What it does:** During the DNS resolution stage, a blocking result is returned or normal resolution is not provided for the hit domain.<br>
**Possible result:** Subsequent connections to the ad server cannot be established, preventing related network ad assets from loading.

### Coverage

Both (source network blocking, conditional)｜Advertising and tracking domains that hit hosts/blocklist in DNS query

### Intervention point

Local VPN (VpnService) + DNS/hosts blacklist
