### What it does

Uses screenshots and YOLOv5/TFLite/TorchScript to detect the "skip" button location and automatically click it via coordinates.

### Limits and notes

It is a prototype solution; the effect depends on the training data and model generalization ability, there may be a calculation delay, and it cannot prevent the ad itself from loading.

### Before use

Only grant accessibility permissions to trusted sources

## Technical notes

### Working method

**Where it starts:** skip_ads_android Get the current screenshot.<br>
**How it decides:** Uses YOLOv5/TFLite/TorchScript target detection model to determine whether there is a "skip" button in the image and output the detection frame coordinates.<br>
**What it does:** Perform automatic taps at the UI layer according to the detected screen coordinates.<br>
**Possible result:** The visually identifiable skip button is automatically clicked; the ad loading process itself is not blocked.

### Coverage
