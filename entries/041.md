### What it does

Allow users to select and block in-app controls such as ads or distracting buttons.

### Limits and notes

Users need to choose which Views to hide; changes in page structure or dynamically generated content will invalidate saved rules, and network/trigger logic may still continue to run.

### Before use

May affect system security or application stability

## Technical notes

### Working method

**Where it starts:** Xposed GodMode allows the user to directly select the View they want to hide in the target app interface,<br>
**How it decides:** and save this choice as a rule.<br>
**What it does:** When the same control is created/layout in the future, Xposed will hide or remove it;<br>
**Possible result:** It relies on manual pointing out "which control is an ad" and does not judge the semantics of ads by itself.

### Coverage

Display-only｜Ad View or other interfering UI controls manually selected by the user

### Intervention point

Xposed + UI View positioning, hiding and layout modification
