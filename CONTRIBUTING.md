# Maintenance and corrections

<a href="CONTRIBUTING.zh-CN.md"><kbd>中文</kbd></a> <kbd>English</kbd>

`data/tools.yml` is the single source of truth. `README.md`, `CATALOG.md`, and the pages under `entries/` are generated from it, so please do not edit generated files directly.

If a name, link, platform, permission, deployment effort, status, working method, or limitation is incorrect, please create an Issue and provide the tool name or permanent ID, the field that needs correction, and a verifiable source. If the same tool has different deployment paths, describe the requirements of each path separately.

Prefer official websites, official app stores, source repositories, and developer documentation. Third-party reports should only be used for clearly dated historical facts and cannot by themselves establish current availability or implementation behavior. Inclusion is for informational purposes only and does not imply a recommendation or safety guarantee.
